Module 1 • Topic 07

Generative AI کیا ہے؟

Text، images، videos، music، code اور creative content بنانے والی AI کو سمجھیں۔

Generative AI کا مطلب

Generative AI وہ AI ہے جو نیا content generate کرتی ہے۔ یہ user کے prompt کی بنیاد پر paragraphs، captions، emails، reports، images، videos، scripts، music ideas، code اور presentations بنا سکتی ہے۔

Prompt کیوں اہم ہے؟

Generative AI کا output prompt پر بہت depend کرتا ہے۔ اگر آپ vague instruction دیں گے تو answer بھی vague ہو سکتا ہے۔ اگر آپ task، audience، tone، format، length اور example دیں گے تو result بہتر ہو گا۔

Generative AI کیا کر سکتی ہے؟

یہ brainstorming، writing، editing، translation، summarization، design concepts، ad copy، lesson plans، quiz questions، customer replies، social media calendars، video scripts اور basic code میں مدد کر سکتی ہے۔

حدود اور احتیاط

Generative AI غلط facts دے سکتی ہے، outdated information استعمال کر سکتی ہے، یا ایسا content بنا سکتی ہے جو legally یا ethically review مانگتا ہو۔ اس لیے important work میں human review، fact-checking اور source verification ضروری ہے۔

اہم نکات

  • Generative AI نیا content create کرتی ہے۔
  • Prompt جتنا clear ہو، output اتنا بہتر ہوتا ہے۔
  • یہ creative assistant ہے، final authority نہیں۔
  • Fact-checking ضروری ہے، خاص طور پر sensitive topics میں۔
یاد رکھیں: AI کو ایک مددگار assistant سمجھیں۔ بہتر results کے لیے clear instructions دیں اور اہم معلومات کو خود verify کریں۔

Quick Quiz

جواب select کریں اور check button دبائیں۔

1. Generative AI کیا بنا سکتی ہے؟

2. اچھے output کے لیے کیا ضروری ہے؟

3. Generative AI کے output کو کب review کرنا چاہیے؟
